# dimcode-mirror

Release binaries of dimcode, built from the private [dimensionalOS/dimcode](https://github.com/dimensionalOS/dimcode); source is not here.

Each release has `dimcode-<os>-<arch>.gz` (linux-x64, linux-arm64, darwin-arm64, darwin-x64), `SHA256SUMS`, and the `dimos.yaml` that dimOS Desktop reads to install them.
